# CloudScale AI Pricing & Packaging Tiers

## Starter Tier ($1,500 / month)
- **Target Audience:** Startups and small teams (under 50 employees).
- **Includes:** Up to 100,000 API requests/month, standard email support (48-hour SLA), shared cloud hosting.
- **Limitations:** No custom SSO, no HIPAA/BAA compliance, no dedicated Slack channel.

## Growth Tier ($4,500 / month)
- **Target Audience:** Mid-market companies (50 to 500 employees).
- **Includes:** Up to 1,000,000 API requests/month, SAML SSO, priority support (8-hour SLA), SOC2 Type II compliance report, and up to 3 custom webhook integrations.

## Enterprise Tier ($12,000+ / month)
- **Target Audience:** Large enterprises (500+ employees) or regulated industries (Fintech, Healthcare).
- **Includes:** Unlimited API requests, VPC peering / single-tenant deployment, HIPAA BAA & GDPR DPA, 99.99% uptime SLA, 1-hour emergency support, and a dedicated Solutions Architect.
